# Calibration methodology

## Current state

The current synthetic cohort is reproducible and deliberately labelled **illustrative**. It is not yet a calibrated estimate of the West Yorkshire population or service demand.

## Target method

1. Establish an NHS West Yorkshire place layer and a civic geography layer, documenting the difference between Bradford District and Craven and the five West Yorkshire local-authority areas.
2. Use dated public demographic distributions, preferably LSOA or MSOA where available, to calibrate age, sex, household, living-arrangement, ethnicity, disability and unpaid-carer context.
3. Join English Indices of Deprivation 2025 at LSOA level.
4. Use public OHID / NHS England admissions context and NHSBSA prescribing aggregates only for place-level or practice-level population learning.
5. Generate synthetic operating events separately from the synthetic population table.
6. Publish the source date, geography, transformation, limitation and validation comparison in the calibration manifest.

## Key limitation

Public data cannot state who currently requires an intervention, owns an action, has a telecare device, has fallen, has accepted a handover or has had a medicines review. Those require an authorised local pilot and must not be inferred from public statistics.
