# Public-data intake boundary

This folder is reserved for dated, documented public extracts used to calibrate aggregate synthetic distributions.

Do not place patient-level, service-user, confidential, restricted or live operational data here. Every public extract should be recorded in `docs/source_register.csv` with its publisher, publication date, download date, geography, licence, intended use and limitation.

The target source families are ONS and Nomis, English Indices of Deprivation 2025, OHID Fingertips, NHSBSA prescribing data, NHS England published activity and relevant West Yorkshire place observatories or JSNAs.
